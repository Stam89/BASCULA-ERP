# Aplicaciones necesarias

## Obligatorias

1. GitHub Desktop
   - Para subir el proyecto a GitHub.
   - Para ver cambios, hacer commit y push.

2. Visual Studio Code
   - Para editar backend, base de datos, documentacion y panel web.

3. Android Studio
   - Para abrir `android-app/`.
   - Para compilar la app Android de planta.

4. PostgreSQL
   - Base de datos principal del ERP.
   - Nombre sugerido de base: `bascula_erp`.

5. Node.js LTS
   - Necesario para correr `backend/` y `web-admin/`.

6. Postman o Insomnia
   - Para probar la API antes de conectar todas las pantallas.

## Hardware recomendado

1. Impresora termica Bluetooth 58mm compatible con ESC/POS.
2. Telefono Android para planta.
3. Computadora administrativa para caja y oficina.
4. Bascula con indicador digital. En la primera version el peso puede ingresarse manualmente; luego se puede conectar por puerto serial/USB si el indicador lo permite.
